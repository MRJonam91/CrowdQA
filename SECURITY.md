# Security Policy / Politica di Sicurezza

## 🇮🇹 Italiano

### Segnalazione di vulnerabilità
Se riscontri una vulnerabilità di sicurezza in CrowdQA, ti chiediamo cortesemente di **non aprire una issue pubblica**.

Invia una segnalazione dettagliata via email a:
**[fbxmano@gmail.com](mailto:fbxmano@gmail.com)**

Includi:
- Descrizione dettagliata della vulnerabilità.
- Passaggi riproducibili o proof-of-concept (PoC).
- Impatto potenziale (es. bypass di sanitizzazione PII o manomissione consensi).

### Politica di disclosure coordinata
Adottiamo una finestra di disclosure coordinata di **90 giorni**. Ci impegniamo a:
1. Confermare la ricezione entro 48 ore.
2. Fornire un piano di rimedio e aggiornamenti regolari.
3. Rilasciare una patch di sicurezza prima di qualsiasi divulgazione pubblica.

---

## 🇬🇧 English

### Reporting a Vulnerability
If you discover a security vulnerability within CrowdQA, please **do not open a public issue**.

Send a detailed report via email to:
**[fbxmano@gmail.com](mailto:fbxmano@gmail.com)**

Please include:
- A clear description of the vulnerability.
- Steps to reproduce or proof-of-concept (PoC).
- Potential impact assessment (e.g. PII leak in sanitization, consent tampering).

### Coordinated 90-Day Disclosure Policy
We observe a **90-day coordinated vulnerability disclosure** policy:
1. Acknowledgement of report within 48 hours.
2. Regular status updates on reproduction and patch development.
3. Coordinated security fix release prior to public advisory.
